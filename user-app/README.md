# 歩歩〜HoHo〜 利用者アプリ・管理者画面（試作）

Figma「PD」に描かれた **すべての画面**（はじめての設定・ログイン・ホームと冒険・記録・わたし・管理者画面のスマホ版とPC版）を、ボタンまで動く画面にした試作です。
要件定義書（M-01〜M-19・N-01〜N-19）と 16章で決まったことに そって作っています。

## VS Code で動かす

リポジトリの `user-app` フォルダを VS Code で開き、ターミナルで次を実行します（リポジトリのいちばん上を開いたときは、先に `cd user-app`）。

```bash
npm install
npm run dev
```

- ブラウザで <http://localhost:5173> を開きます。パソコンでは 左に確認用パネル、右に Figma と同じ 393×852 のスマホの枠（PC版の管理者画面は 1440×1024 の枠）が出ます。スマホでは画面いっぱいに出ます。
- 同じ Wi-Fi のスマホからは、ターミナルに出る `Network:` のアドレスで開けます。
- VS Code の「実行とデバッグ」→「歩歩：開発サーバーをChromeで開く」でも開けます（先に `npm run dev`）。

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | 開発サーバー（保存するとすぐ反映） |
| `npm run typecheck` | 型のチェック |
| `npm run build` | 本番用のビルド（`dist/`） |
| `npm run build:demo` | デモURL用の1ファイル版（`artifact/hoho-demo.html`） |
| `npm run e2e` | 全ボタンの動作テスト（`e2e/buttons.e2e.mjs`）。先に `npm run dev` で開発サーバーを起動しておく。入っている Chrome を使う（Edge は `E2E_CHANNEL=msedge`、別のアドレスは `BASE=…`） |

## デモの使い方（確認用パネル）

  screens/register/     U-00〜U-10

## Figma に描かれていない部分（試作で決めたこと・チームで確認したいこと）

- **冒険のきまり（案）**：1歩＝経験値1。レベル L→L+1 に いる経験値は 3,000＋50×L 歩（Figma の「あと1,450歩で 20マス中12マス」に合わせた数）。あまりは持ち越し（16章で決定）。750歩ごとに敵に会い、自動でたおして 10ポイント。成果は 立ち止まって開いたときに まとめて見せます（16章で決定）。
- **距離とカロリー（案）**：歩幅＝身長×0.37、カロリー＝体重×歩数×0.00062kcal（3.5メッツ・1分に約99歩の散歩にあたる）。Figma の数（3,210歩→1.8km・100kcal、1週間 958kcal など）と すべて一致します。性別は使いません。
- **前週との差**：先週の同じ曜日と くらべる案（AM-03 の提案）。今日の記録が届いていない人は「―」。へった日も 赤くしません（N-11）。
- **目標歩数を だれが決めるか（16章で未決）**：本人の「わたし」と 管理者画面の「変更する」の どちらからでも変えられるようにしています。
- **データの時点（N-19）**：一覧は 開いたとき／「更新」「最新にする」を押したときの データを出し、その時刻を表示します。測定結果は その人の最終受信の時刻です。
- **ログアウト**：利用者アプリは「わたし → お名前・身長・体重」の下に置き、確認の窓を出します。
- **介護レベル**：管理者側が登録する案（12章）。未登録の人は「なし」と出します。
- **大きな一覧・入力の注意・ログイン失敗の文・身長体重の最初の数・合言葉の文字（L-03）**：前回と同じ（登録・ログインの画面）。

## Figma の書き出し上限のため 近い絵で代わりにしているところ

作業の途中で Figma の読み出しの回数が上限（Starter プラン）に達したため、次の4つは Figma の絵を書き出せず、近いもので代わりにしています。

- AM-01 の上の 冒険の背景の帯 → ホームの背景（H-01）の一部
- AP-01 の左の絵（空・雲・山・草地） → はじめの画面（U-00）の背景を 720幅に広げたもの
- AP-02 の 虫めがねのアイコン、▲▼ と「！」の印 → CSS でえがいた形

## 本実装に向けて

- **管理者のログインは 試作では ブラウザの中だけ** で確かめています（パスワードも画面のコードの中）。本実装では サーバーで確かめ、見られる人（N-14）も サーバーで しぼってください。
- `src/lib/store.ts` の関数を サーバーのAPIに置きかえれば、画面は そのまま使えます。歩数は ブラウザで開いている間、スマホの加速度センサーで数えます（要件定義書 M-03）。
- 試作は Web アプリで作ることに決定（11/6）。アプリを閉じている間の計測（バックグラウンド計測）は 作りません。本実装で スマホのアプリにするときは、React で作っているので React Native（Expo）にも移しやすい形です。
- フォントは今は Google Fonts から読み込んでいます。本実装ではアプリに同梱する。
