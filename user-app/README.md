# 歩歩〜HoHo〜 利用者アプリ（試作）

Figma「PD」の **2 はじめての設定（登録）U-00〜U-10** と **3 ログイン（2回目以降）L-01〜L-03** を、そのまま動く画面にした試作です。
要件定義書（M-01 利用者登録・M-02 ログイン・N-01〜N-16）にそって作っています。

## VS Code で動かす

リポジトリの `user-app` フォルダを VS Code で開き、ターミナルで次を実行します（リポジトリのいちばん上を開いたときは、先に `cd user-app`）。

```bash
npm install
npm run dev
```

- ブラウザで <http://localhost:5173> を開きます。パソコンでは Figma と同じ 393×852 のスマホの枠に、スマホでは画面いっぱいに出ます。
- 同じ Wi-Fi のスマホからは、ターミナルに出る `Network:` のアドレスで開けます。
- VS Code の「実行とデバッグ」→「歩歩：開発サーバーをChromeで開く」でも開けます（先に `npm run dev`）。

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | 開発サーバー（保存するとすぐ反映） |
| `npm run typecheck` | 型のチェック |
| `npm run build` | 本番用のビルド（`dist/`） |
| `npm run build:demo` | デモURL用の1ファイル版（`artifact/hoho-demo.html`） |

## フォルダの中身

```
src/
  styles/tokens.css     色・文字の大きさ・形（Figma「1 デザインのきまり」）
  components/           部品（主ボタン・戻る・進み具合・入力欄・選ぶ欄・大きな一覧・選択肢・数を選ぶ・ローマ字のボタン・RPGウィンドウ など）
  screens/register/     U-00〜U-10
  screens/login/        L-01〜L-03
  flow/                 画面の順番と、入力中の内容
  lib/                  和暦の変換・ログインの照合・端末への保存・スマホの許可
  demo/                 パソコンで見るときのスマホの枠と確認用パネル（本実装では使わない）
  assets/               Figma から書き出したドット絵・アイコン（SVG）
```

## Figma に描かれていない部分（試作で決めたこと）

- **大きな一覧（U-02 注記）**：年は和暦と西暦の一覧、月は3列、日は5列の大きなボタン。1つ押すと決まって閉じます。元号が変わった年（1926年・1989年）は、月日が決まるまで両方を出します。
- **まだ選んでいない・入れていないとき**：「つぎへ」は押せるままにして、押したときに何が足りないかを 朱色と「！」で伝えます。
- **ログインに失敗したとき**：どれが合わなかったかは言わず（N-13）、「施設のスタッフに 声をかけてください」と出します。
- **身長・体重の最初の数**：選んだ性別のおよその平均（女性 152cm・50kg など）から始めます。
- **目標歩数**：1,000〜20,000歩。「めやす」は 1分100歩として時間に言いかえます。
- **合言葉の文字（L-03 案）**：L-03 の注記どおり、登録にも「文字を決める」画面（U-02b）を足しました。確認用パネルで使う／使わないを切りかえられます。使わないときは Figma どおり 登録8手順・ログイン2手順になります。
- **スマホの許可（U-09）**：ブラウザの試作では許可画面は出さずに進みます。`src/lib/permissions.ts` に本実装でやることを書いています。
- **保存先**：登録はブラウザの中（localStorage）だけです。`src/lib/auth.ts` の関数をサーバーのAPIに置きかえれば、画面はそのまま使えます。

## 本実装に向けて

- スマホのアプリ（iPhone・Android）にするか、Web アプリのままにするかを決める。部品と画面の組み立ては React なので、React Native（Expo）にも移しやすい形にしています。
- 文字の大きさ（M-02 / N-01）の3段階は `tokens.css` に用意済み。`<html data-text-size="large">` で切りかわります（マイページの画面で使う）。
- フォントは今は Google Fonts から読み込んでいます。本実装ではアプリに同梱する。
