## 1. 世界のあらすじ

1. むかしから、この里の まんなかの 丘には「おおてまり」という 大きな てまりが ありました。
2. おおてまりは 七色の 糸で まかれていて、その色が 里に 春・夏・秋・冬を めぐらせて いました。
3. ところが ある春の朝、長い年月で ゆるんだ 糸が 風に ふかれて ほどけ、里じゅうに とんでいって しまいました。
4. おおてまりは 白くなり、里の 季節の色も うすく なりました。だれかが わるいわけでは ありません。
5. とんでいった 糸は、季節や 天気や 身近なものの「いたずらもの」たちが ひろって、あそんでいます。
6. あなたは 糸を まく人、「まきて」です。一歩 あるくと、糸が 一歩ぶん のびます。
7. いたずらものは、たおすと おとなしくなり、もっていた 糸（色）を 少し かえしてくれます。
8. 歩いている間は 画面を さわりません。立ち止まって ひらくと、その間に のびた 糸と、もどった 色を まとめて 見られます。
9. 休んだ日は、まいた 糸が てまりに「なじむ」日です。なじんだ 糸は ほどけにくく、次の色が きれいに のります。
10. 七つの 道を 歩きおえると、おおてまりに 七色が もどり、里に 四季が めぐりはじめます。そのあとは、もう一まわり ていねいに まいていく「巡り（めぐり）」が はじまります。

### この世界で 守ること

- **悪者は いない**：糸が ほどけたのは 年月と 風のせい。いたずらものは 糸で あそんでいるだけ。
- **失敗が ない**：時間切れ・やりなおし・糸が へること は ない。歩いた分は かならず のこる。
- **休みも 物語の 一部**：歩かない日は「なじませの日」。責める ことばは 出さない（N-11）。
- **止まって 見る**：物語は「歩いた あとで、成果を 見る」形だけで 進む（M-07、M-11）。

- 「1,500歩 あるきました。糸が 1,500歩ぶん のびました。」

## 4. 名前の決まり

### 名前（ひらがな）

- ひらがな 3〜6字。小さい「ゃ・ゅ・ょ・っ」も 1字と 数える。カタカナ・漢字・記号は 使わない。
- **声に出すと、何のことか 思いうかぶ** ことを いちばんに する。もとの ことばを くずしすぎない。
- 型は 4つ。今ある3体の つけ方に そろえた。
  1. そのままの ことば（例：あまぐも、ちょうちん、ゆきだるま）
  2. もの＋ようす・音（例：いしころん、ぴちゃぐつ、からころげた、ゆげやかん）
  3. くりかえし（例：はっぱっぱ、ふうりんりん、いとまきまき）
  4. 人の ような よび名（例：かきべえ、かかしどん、こけしさん、おたまっこ）。「〜っこ」「〜どん」「〜さん」は それぞれ 3体まで
- **ぬし（ボス）** は、その季節の 大きな 自然や 行事の ことばを かざらずに 使う（はなふぶき、さみだれ、まつりばやし、にゅうどう、おおいちょう、どかゆき）。さいごの ぬしだけは 糸の ことば（もつれだま）。
- **えんぎもの（レア）** は、会えたら うれしい 縁起のよいもの（昔話の もも、ほたるの光、福引きの 大あたり、玉手箱、十五夜の うさぎ、茶ばしら、まねきねこ）。七福神に ちなんで 7体。
- **年こしの ぬし（裏ボス）** は、年の おわりと はじまりの ことば（おおみそか、はつひので）。
- **昔話・神話の モチーフは 使ってよい**（決定）。借りるのは みんなの 昔話の「もの」と「ことば」だけで、特定の 絵本・アニメ・ゲームの 絵がらや 人物には にせない。今 入っている もの：どんぶらこ（ももたろうの もも）、たまてばこ（うらしまたろう）、じゅうごや（月の うさぎ）、ころむすび（おむすび ころりん）、ちょきがに・かきべえ・ぺったんうす（さるかに）、おりづる（つるの おんがえし）。人や 神さま そのものは「たおす」相手に しない。
- 1文字ちがい・2文字ちがいの 名前は 作らない。にた ひびき（同じ おわり方の 5字どうし など）も さける。

### id（ローマ字）

- 英小文字だけ（数字は 今回は 使っていない）。ヘボン式。「し＝shi」「ち＝chi」「つ＝tsu」「ふ＝fu」「じ＝ji」「づ＝zu」。
- のばす音は かなの とおりに 書く（おお＝oo、おう＝ou、うう＝uu、ええ＝ee）。
- 「っ」は 次の 子音を 重ねる（はっぱっぱ＝happappa）。「ん」は n。
- 絵の ファイル名は `enemy-<id>.svg`。今ある3体（amagumo・ishikoron・happappa）は 変えない。

- ぬし（ボス）7体と 年こしの ぬし（裏ボス）2体は **32×32マス**（1マス 5px、160×160 の SVG）で 描く（決定）。ふつう・レアは 16×16マス（80×80）。ボスの 目は 2×3マス。
- 絵の もとは `design/sprites/`（文字の マス目と 色の 表）。SVG と 一覧の 画像の 作り方は `design/README.md`。
- 上下左右の はしまで 使う。体は 少なくとも 10マスの はばか 高さを もつ。

- 1体につき 6色まで（りんかくの 墨を ふくむ）。目安は「りんかく・地の色・かげ・ひかり・目印の色・もう1色」。

## 8. 確かめた結果

5章の 表を 短い スクリプト（python）で 読んで 確かめた。スクリプトは 作業場所の 外の 一時フォルダに 置き、終わってから 消した。

### 検査の 中身

- 表の 行（No. が 数字で、列が 7つの 行）を すべて 読む。
- 「にた名前」は、文字の 入れかえ・足す・ぬく の 回数（編集きょり）で 数えた。1回（1文字ちがい）と 2回（2文字ちがい）の 組を どちらも さがした。
- id は、名前の かなを ローマ字に 直した ものと 同じか も 確かめた。
- 図鑑の一言は、空白を のぞいた 字数で 数えた。

## 9. 演出と音の方針

### 場面ごとの 演出と 音

音の ファイルは 使わず、ブラウザの Web Audio で 音を 合成する（著作権の 心配が ない）。「琴」「鈴」「太鼓」「笛」は、その 楽器を 思わせる 合成音の こと。

| 場面 | 画面の 動き | 音 |
| --- | --- | --- |
| 歩きはじめ | 主人公が 1歩 ふみ出し、足もとから 糸が すっと のびる（0.5秒） | 琴を 1音 ぽろん（低めの 1音） |
| 敵に会う | 敵が 右から ゆっくり 入ってくる（0.4秒）。名前を 下に 出す | 鈴を 1回 ちりん |
| たおす | 敵が 小さく 1回 はねて、その道の 色の 糸が 主人公へ 流れる（0.6秒） | 琴を 2音 上がる（ぽろ ろん） |
| アイテム | 小さな 包みが 上から ふわりと おりて 開く（0.5秒） | 鈴を 2回 ちりちりん |
| レベルアップ | 主人公の まわりに 金の 糸が ひとまわり。「レベル ○」を 大きく 出す（1秒） | 琴を 3音 上がり、さいごに 鈴 |
| ボスに会う | 背景の 色が ゆっくり こくなり、ボスが 下から せり上がる（1秒）。のこりの 歩数を 出す | 太鼓を どん・どん と 2回（低く やわらかく）、あとに 笛を 1音 |
| ボスをたおす | ボスが おじぎを して、太い 糸の たばが おおてまりへ とぶ。てまりの 1色が ともる（1.5秒） | 太鼓 1回の あと、琴が 5音 上がって 鈴で おわる |
| エリアをこえる | 画面が 次の 道の 色へ ゆっくり うつる（1.5秒）。道の 名前を 出す | 笛の みじかい ふし（4音）。次の 道の 音色に かわる |
| レアに会う | 敵の まわりに 金の 点が 4つ、ゆっくり 明るくなる（点滅は しない）。「めずらしい」と 出す | 鈴を 3回、少しずつ 高く |
| スタンプ | スタンプが 上から おりて 紙に つく。朱色の しるしが のこる（0.4秒） | 木を うつ ような 低い「とん」 |
| ガチャ | 糸玉が ころがって 止まり、ほどけて 中身が 出る（1.2秒） | 鈴の ころころ（4回 だんだん ゆっくり）、出た ときに 琴 1音 |

### 音の 方向

- **短くて やさしい 和の 音**。1つの 音は 0.2〜1.5秒。同時に 鳴るのは 2音まで。
- 合成の 考え方（案）
  - 琴：三角波を はじく ように 鳴らし、すぐ 小さく する
  - 鈴：高さの 近い 2つの サイン波を 重ね、0.3秒ほどで 消す
  - 太鼓：低い サイン波の 高さを すばやく 下げる。雑音は ごく 少し
  - 笛：サイン波を ゆっくり 立ち上げ、少しだけ ゆらす
- 音階は ヨナ抜き（ド・レ・ミ・ソ・ラ）を もとに する。どの 音を ならべても にごらない。
- エリアごとに 音階と 音色を 少し 変える（案）

| 道 | 音の ふんいき | 変える ところ |
| --- | --- | --- |
| 1 春 | 明るい 琴 | ヨナ抜きの 長調。中くらいの 高さ |
| 2 初夏 | 雨だれの ような 琴 | 同じ 音階で、音の 間を あける。鈴は ひかえめ |
| 3 夏 | まつりの 太鼓と 笛 | 笛を 多めに。はずむ リズム |
| 4 盛夏 | ひろびろした 笛 | 音を 長めに のばす。波の ような ゆっくりした 上下 |
| 5 秋 | しっとりした 琴 | 短調の ヨナ抜き（ラ・シ・ド・ミ・ファ）。少し 低く |
| 6 冬 | しずかな 鈴と 低い 琴 | 音数を へらす。ゆっくり |
| 7 終章 | 琴・鈴・笛が そろう | 春の 音階に もどり、ボスを たおすと 7音が 順に 鳴る |

### 高齢の 方への 配慮

- **大きすぎない**：はじめの 音量は 小さめ（全体の 2〜3割）。音量は「小・中・大」から えらべる。
- **高すぎない**：主な 音は 200〜1,500Hz ほど。きんきんする 高い 音・低すぎる 音は 使わない。
- **おどろかせない**：どの 音も 急に 鳴らさず、少し かけて 立ち上げる。大きな 音・長い 音・くりかえす 音は 使わない。
- **音を 消せる**：マイページに「音 入・切」を 置く。切っても 画面の 文と 絵だけで すべて 分かる（音だけで 伝える ことは 作らない）。
- **動きを へらせる**：マイページに「動きを へらす」を 置く。入れると、動く 演出を やめて 絵と 文を ぱっと 出す。端末の「視差効果を減らす」の 設定にも したがう。
- **画面の ゆれ・点滅は 使わない**。色の うつりかわりは 0.3秒より ゆっくり。動く きょりは 小さく（数マスぶん）。
- 演出の 間も 待たせない。どの 演出も 画面を さわれば すぐ 終わる。

### 歩いている 間の 音（案）

歩いている 間は 画面を 見ないので、音で 進みを 知らせる ことが できる。外で 鳴るので、ひかえめに する。

| 案 | 中身 | よい点 | 気になる点 |
| --- | --- | --- | --- |
| A（おすすめ） | 歩行中の 音は はじめは「切」。本人が「入」に すると、敵を たおした 時に 小さな 鈴が 1回 鳴る。ボスを たおした 時・レベルアップの 時は 鈴が 2回 | 画面を 見なくても 進みが 分かる。歩きスマホを へらせる | 外で 音が 出る。スマホの 音量に よっては 聞こえない |
| B | 歩行中は 何も 鳴らさない。止まって 開いた 時に まとめて 鳴らす | しずか。まわりに めいわくが ない | 歩いている 間の 楽しみが ない |

- 鳴るのは 750歩ごとに 1回ほど（数分に 1回）。つづけては 鳴らさない。
- ブラウザは、画面を 一度 さわった あとで ないと 音を 出せない。歩きはじめる 前に 開いて さわって いれば 鳴らせる。画面を 消した 間は 歩数も 音も 止まる（試作の 制約）。
