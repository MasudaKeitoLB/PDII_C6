# 設計：アニメーション（段階B〜E）

作成：2026-11-17　もとの文書：[世界観](世界観.md)（9章 演出と音の方針）・[設計-ゲームの核](設計-ゲームの核.md)

## きまり（どの段階にも かかる）

- 動きを へらす（「わたし」の設定・端末の「視差効果を減らす」）のときは、新しい動きを すべて止める。戦闘は 結果（たおした・ポイント）を すぐ出す
- 画面の ゆれ・点滅は 使わない。色の うつりかわりは 0.3秒より ゆっくり。動く きょりは 小さく
- 音は 今の `sound.ts` の 音だけ。音が「切」なら 鳴らさない（`playSound` が 守る）
- 成果の画面の 文字と絵は はじめから DOM に置き、見た目（opacity・transform・はば）だけを 動かす
- 絵は デザイン担当が 同時に 作っている。`import.meta.glob` で 読み、無ければ 今の hero.svg や CSS の道に 切りかえる（404 を出さない）
- テストする 純粋な関数・データ（`src/lib/*.ts`・`src/data/*.ts`）は React・.svg・import.meta.glob を入れない

## B 歩行中の画面（WalkingLock）

- 今の 絵（walking.svg）の 場所に、はばいっぱいの 道の場面（高さ 190px）を置く。上から 空（エリアの色の グラデーション）→ 遠くの景色（home-bg を 左右反転で つないで ゆっくり、60秒で 790px）→ 近くの 道の帯（160×60 を くり返し、2秒で 160px）→ 主人公
- 道の帯が 無い エリアは、エリアの色の 草と 土の道を CSS で描く（同じ 160px の くり返し）
- 主人公は 4コマを 0.8秒で 回す。コマが 無ければ hero.svg を 3px だけ 上下させる
- `walk==='walking'` で 流れる。`'stopping'` になったら、Web Animations の `playbackRate` を 1秒で ほぼ 0 まで 下げてから `pause()` で 止め、立った 絵に する（`data-walk-scene`：moving → stopping → stopped）。速さ 0 の まま 止めると 位置が はじめに もどって 見えるので、止めてから 速さを 1 に もどす。動きを へらす ときは `still`（はじめから 止まった 絵）
- 文字・aria・操作できない しくみは そのまま。場面は `aria-hidden`

## C 戦闘アニメーション＋HPバー

- `battlePlan(pending)` が 回（ラウンド）の 表を作る。1回 = 1体：「出る（0〜22%）→ 前に出て てまり（22〜40%）→ HPが へる（30〜72%）→ 光の粒で 消える（72〜92%）→ ポイントが 飛ぶ」
  - 小さい敵：HP 750 → 0。ボス：はじめは「前の残り」（`bossBefore`。無ければ ボスの 全部の歩数）→ 0。戦っている途中の ボスは さいごの回で 前の残り → 今の残り（消えない）
  - 長さ：ふつう 1.5秒・レア 1.8秒・ボス 2.2秒。4回 以上は 早送り（0.8・1.2・1.6秒）。回は 8回まで（ボス・レアを 先に えらび、のこりの ふつうの敵の ポイントは さいごに 足す）
  - エリアを こえた ときは、その ボスの回の あとに 1.8秒の「エリアをこえる」を はさむ
- 時計 `t`（秒）から、各回の `data-phase`（wait/enter/attack/drain/vanish/gone/stay）・HP・主人公の ポーズ・ポイントを 計算する。見た目の 動きは CSS（transition・animation）
- 成果の画面を 開いたまま 歩きはじめたら（`walk !== 'idle'`）、その画面では 時計を おわりに し、音も 予約しない（ロックの下で 記録の たびに 鳴らしなおさない。止まった あとも 鳴らしなおさない）
- 画面を さわると（`useSkipOnTouch`）t を おわりに する。動きを へらす ときも はじめから おわり。おわりの 形：敵は 消え、HPバーは 0（途中の ボスは 今の残り）、主人公は 勝ちのポーズ（勝ちの コマが 無ければ hero.svg で 1回 小さく はねる）
- ボスの 長い バーは 右はしを 場面の x=385 に そろえる（場面から はみ出さない）
- たおした敵の 小さい絵の 列は、その敵を たおした ときに 出る。できごとの行は 戦闘の あと
- `PendingAdventure.bossBefore?`（任意）：成果を 作った ときの ボスの残り。`walk` が 入れ、古い記録は `normalizeGame` が「いまの位置 − 成果の歩数」の 所の ボスで うめる（2回 通しても 同じ）
- ホーム：次の敵の 頭の上に `HpBar`（`nextEnemyHp`：ふつうは「次の出会いまで あと ○歩 / 750」、ボスは ボスの残り）。文字が「とても大きい」ときと ボスの ときは 頭の上に 場所が ないので 足もとの 下に 右を そろえて 出す（ポイントの枠・エリア名に 重ねない）。頭の上の ときも まん中は x=286 より 右に しない（文字が 大きいときに 右はしから はみ出さない）。足もとの下の ときは x=160〜383 の 箱の 中に 右を そろえ、数が 長いときは バーが ちぢむ（主人公 x=67〜152 に 重ねない）。左上の「ボス あと ○歩」の行は 残す。ボスの バーは 読み上げない（左上の 行で 読む）
- バーの色は 緑（`#3E9A63`）→ 金（`#FFC53D`）。赤は 使わない。バーの 太さは 文字の大きさで 8・10・12px（ボスは +4px）

| できごと | 画面 | 音（`sound.ts`） |
| --- | --- | --- |

- 音の 名前は 今の `resultSounds` で えらび（2つまで）、時刻だけ 演出に 合わせる。重ならないよう あとの 音を ずらす。タップで とばしたら のこりの 音は 鳴らさない。動きを へらす ときは 今と 同じく 開いたときに 順に 鳴らす（タップで 2つめも 止める）
- てまりは 敵の 手前まで 0.5秒で 飛ぶ（速すぎない）

## E 敵ごとの 動きの型

- 6種類：`float`（ふわふわ浮く）・`hop`（ぴょんと跳ねる）・`sway`（ゆらゆら揺れる）・`spin`（ゆっくり回る）・`glow`（ほのかに光る。体の うしろの 光の 層の opacity だけを 3.6秒で ゆっくり 動かす。filter は 使わない）・`drip`（ぽたぽた：下に 少し つぶれて もどる）
- ボス・裏ボス（大きな体）は `sway` か `glow` だけ（跳ねたり 回ったりすると 画面が ゆれて 見え、ドット絵も にじむ）
- 世界観.md 5章の 姿から 決める（雲・虫・鳥 → float、石・かえる・はねる物 → hop、葉・つるした物 → sway、うず・こま → spin、明かり・レア → glow、しずく・雨・とける物 → drip）
- どの keyframes も はじめと おわりが ふつうの 形（端末の 動きを へらす で 0.01秒に なっても かたむいたまま 止まらない）
- ホームの 次の敵と、戦闘の 敵の 登場の あとで 使う
